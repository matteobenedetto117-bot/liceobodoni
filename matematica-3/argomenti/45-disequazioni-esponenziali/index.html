Disequazioni esponenziali

Incognita all'esponente in una disuguaglianza: quando il verso si conserva?

Confronto fra potenze della stessa base ($a>0,\ a\ne1$)

$$a>1:\quad a^t>a^z\ \Longleftrightarrow\ t>z\qquad\text{(verso conservato)}$$

$$0<a<1:\quad a^t>a^z\ \Longleftrightarrow\ t<z\qquad\text{(verso invertito)}$$

$a=2>1$: $t>z$, $a^t>a^z$

$a=\frac12<1$: $t<z$, $a^t>a^z$

Una potenza a base positiva è sempre positiva:

  • $2^{3x}>-5$ → vera per ogni $x\in\mathbb{R}$;
  • $-2^{3x}>5$, cioè $2^{3x}<-5$ → impossibile;
  • $-2^{3x}>-5$, cioè $2^{3x}<5$ → da risolvere;
  • $(-2)^{3x}>(-2)^5$ → base negativa: non rispetta le condizioni di esistenza.

Esempio 1

Risolvere $\left(\frac18\right)^x>\frac14$.

$$\left(\frac12\right)^{3x}>\left(\frac12\right)^2\ \Rightarrow\ 3x<2\ \Rightarrow\ x<\frac23\qquad\left(a=\tfrac12<1\right)$$

Esempio 2

Risolvere $3^x-2\cdot3^{2-x}<7$, con $z=3^x$, $z>0$.

$$z-\frac{18}{z}-7<0\ \Rightarrow\ z^2-7z-18<0\qquad z_1=-2,\ \ z_2=9$$

$$-2<z<9,\ \ z>0\ \Rightarrow\ 3^x<3^2\ \Rightarrow\ x<2$$

Verso opposto ($>7$):

$$z<-2\ \lor\ z>9,\ \ z>0\ \Rightarrow\ 3^x>3^2\ \Rightarrow\ x>2$$

Attenzione

Si moltiplica per $z$ senza cambiare verso perché $z=3^x>0$.
