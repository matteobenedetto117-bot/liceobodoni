Funzioni definite a tratti

Regola diversa su intervalli diversi di $x$: come si scrive la funzione?

Funzione definita a tratti

Una formula per ogni intervallo, raccolte da una parentesi graffa:

$$y=\begin{cases} f_1(x) & \text{se } x \in I_1\\ f_2(x) & \text{se } x \in I_2\\ \ \ \vdots \end{cases}$$

Intervalli senza sovrapposizioni: ogni $x$ ricade in un solo tratto.

Valore assoluto

$$y=|x|=\begin{cases} x & \text{se } x\ge 0\\ -x & \text{se } x<0 \end{cases}$$

Due semirette dall'origine: pendenza $1$ per $x\ge0$, pendenza $-1$ per $x<0$

Esempio

$$y=\begin{cases} 3x & \text{se } x<-5\\ x^2 & \text{se } -5\le x<7\\ \sqrt{x}+8 & \text{se } x\ge 7 \end{cases}$$

Calcolare i valori dei tratti adiacenti agli estremi $x=-5$ e $x=7$.

$$x=-5:\quad 3\cdot(-5)=-15\ne(-5)^2=25\qquad x=7:\quad 7^2=49\ne\sqrt7+8\approx10{,}6$$

  • valori uguali → tratti uniti;
  • valori diversi → salto nel grafico.
