Dominio delle funzioni del tipo $[f(x)]^{g(x)}$

Nella funzione esponenziale $y=a^x$ la base è un numero fissato e positivo. Se al posto di quel numero compare un'espressione in $x$, oppure se anche l'esponente dipende da $x$, il dominio non si legge più a colpo d'occhio: va ricavato imponendo che l'elevamento a potenza abbia senso. Distinguiamo tre casi, a seconda che a variare con $x$ sia la base, l'esponente, o entrambi.

Base costante, esponente variabile

Nel primo caso la base resta un numero fissato $a$, mentre l'esponente è un'espressione $f(x)$ al posto della semplice $x$. Vale la stessa condizione già nota per la funzione esponenziale elementare: basta che la base sia positiva, e ci si mette nel dominio di $f(x)$.

Regola

$y=a^{f(x)}$, con $a\in\mathbb{R}$: la funzione esiste se $a>0$, nel dominio di $f(x)$.

Esempi

$y=3^{\sqrt{x-1}}$: la base $3$ è sempre positiva, basta il dominio dell'esponente: $$x-1\ge 0 \quad\Longrightarrow\quad \text{C.E.}: x\ge 1$$

$y=2^{\frac{x-1}{x}}$: la base $2$ è sempre positiva, basta il dominio dell'esponente: $\text{C.E.}: x\ne 0$.

$y=(-3)^{x^2+1}$: la base è negativa, quindi la condizione $a>0$ non è mai soddisfatta: $\text{C.E.}: \nexists\, x\in\mathbb{R}$.

Base variabile, esponente costante

Capovolgiamo ora i ruoli: l'esponente è un numero fissato $\alpha$, la base è un'espressione $f(x)$. La condizione su $f(x)$ dipende dal segno di $\alpha$. Se $\alpha$ è positivo basta che la base non sia negativa, perché $0$ elevato a un esponente positivo resta $0$; se $\alpha$ è negativo la base compare a denominatore (un esponente negativo è l'inverso di una potenza) e quindi non può annullarsi: deve essere strettamente positiva.

Regola

$y=[f(x)]^\alpha$, con $\alpha\in\mathbb{R}$ costante, nel dominio di $f(x)$:

se $\alpha\in\mathbb{R}^+$, C.E.: $f(x)\ge 0$;   se $\alpha\in\mathbb{R}^-$, C.E.: $f(x)>0$.

Esempi

$y=(x^2-1)^{\sqrt2}$: l'esponente $\sqrt2$ è positivo, quindi $$x^2-1\ge 0 \quad\Longrightarrow\quad \text{C.E.}: x\le -1 \ \vee\ x\ge 1$$

$y=(x^2-4)^{-\sqrt2}$: l'esponente è negativo, la base deve essere strettamente positiva: $$x^2-4>0 \quad\Longrightarrow\quad \text{C.E.}: x<-2 \ \vee\ x>2$$

$y=\left(\dfrac{x+3}{x-1}\right)^{\pi}$: l'esponente $\pi$ è positivo, quindi serve $\dfrac{x+3}{x-1}\ge 0$. Studiamo il segno di numeratore e denominatore:

Base ed esponente entrambi variabili

Il caso più generale è quello in cui sia la base sia l'esponente dipendono da $x$. Qui non basta più che la base sia non negativa: deve essere strettamente positiva, perché l'esponente $g(x)$ varia con continuità e un valore nullo o negativo della base non garantirebbe un risultato reale ben definito per ogni $x$.

Regola

$y=[f(x)]^{g(x)}$ esiste, nel dominio di $g(x)$, se e solo se $f(x)>0$.

Esempio

$y=(4x^2-1)^{\sqrt{x}}$. Vanno imposte insieme il dominio dell'esponente e la positività della base:

$$\begin{cases} x\ge 0 & \text{(dominio di }\sqrt{x}\text{)}\\ 4x^2-1>0 & \text{(base positiva)}\end{cases}$$

La seconda condizione si scompone come differenza di quadrati: $$4x^2-1>0 \quad\Longrightarrow\quad (2x-1)(2x+1)>0 \quad\Longrightarrow\quad x<-\tfrac12\ \vee\ x>\tfrac12$$

Mettendo a sistema con $x\ge 0$, l'unica parte comune alle due condizioni è $x>\tfrac12$:

$$\text{C.E.}: x>\tfrac12$$
