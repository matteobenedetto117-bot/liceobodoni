Proprietà dei logaritmi

Il logaritmo trasforma un prodotto in una somma, un quoziente in una differenza e una potenza in un prodotto. Sono le tre proprietà che rendono maneggevoli le espressioni con i logaritmi e che serviranno per risolvere equazioni come $5^x=4$, dove le basi non si lasciano ricondurre l'una all'altra.

In tutte e tre le proprietà seguenti si suppone $a>0$, $a\neq1$, $b>0$, $c>0$: sono le stesse condizioni che rendono definito il logaritmo.

Logaritmo di un prodotto

Proprietà

$$\log_a(b\cdot c) = \log_a b + \log_a c$$

Dimostrazione

Poniamo $x=\log_a b$ e $y=\log_a c$, cioè $a^x=b$ e $a^y=c$. Moltiplicando membro a membro: $$b\cdot c = a^x\cdot a^y = a^{x+y}.$$ Ma allora $x+y$ è, per definizione, il logaritmo in base $a$ di $b\cdot c$: $$\log_a(b\cdot c) = x+y = \log_a b + \log_a c.$$

Logaritmo di un quoziente

Proprietà

$$\log_a \frac{b}{c} = \log_a b - \log_a c$$ Si dimostra con lo stesso ragionamento della proprietà precedente, applicato al quoziente $a^x/a^y=a^{x-y}$.

Logaritmo di una potenza

Proprietà

$$\log_a b^n = n\log_a b$$

Dimostrazione

Poniamo $x=\log_a b$, cioè $a^x=b$. Elevando entrambi i membri a $n$: $$(a^x)^n=b^n \quad\Longrightarrow\quad a^{nx}=b^n.$$ Ciò significa che $nx$ è il logaritmo in base $a$ di $b^n$: $$n\log_a b = nx = \log_a b^n.$$

Esempio

Risolviamo $5^x=4$. Applichiamo il logaritmo in base $5$ a entrambi i membri: $$\log_5 5^x = \log_5 4.$$ A sinistra, per la proprietà appena dimostrata, $\log_5 5^x = x\log_5 5 = x$, perché $\log_5 5=1$. Resta $$x=\log_5 4.$$
