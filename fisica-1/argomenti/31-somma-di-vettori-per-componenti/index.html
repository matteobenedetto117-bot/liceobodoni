Forze e vettori · Unità 30

Somma di vettori per componenti

Due forze sullo stesso corpo: $F_1 = 120\ \text{N}$ orizzontale e $F_2 = 140\ \text{N}$ inclinata di $28°$ sull'asse $x$. Quanto vale la risultante $\vec R$?

Code nell'origine; angoli dall'asse $x$; frecce in scala

Componenti di ciascuna forza, con l'angolo misurato dall'asse $x$:

$$\begin{aligned} F_{1x} &= 120\ \text{N}\cdot\cos 0° = 120\ \text{N}\\ F_{1y} &= 120\ \text{N}\cdot\sin 0° = 0\end{aligned} \qquad\qquad \vec{F_1} = (120\ \text{N}\,;\ 0)$$

$$\begin{aligned} F_{2x} &= 140\ \text{N}\cdot\cos 28° = 124\ \text{N}\\ F_{2y} &= 140\ \text{N}\cdot\sin 28° = 66\ \text{N}\end{aligned} \qquad\qquad \vec{F_2} = (124\ \text{N}\,;\ 66\ \text{N})$$

Le componenti $x$ si sommano fra loro, le componenti $y$ fra loro, ciascuna col proprio segno:

Componenti della risultante

$$R_x = F_{1x} + F_{2x} \qquad\qquad R_y = F_{1y} + F_{2y}$$

$$\vec R = (120\ \text{N} + 124\ \text{N}\,;\ 0 + 66\ \text{N}) = (244\ \text{N}\,;\ 66\ \text{N})$$

Errore tipico

Si sommano le componenti, non i moduli: $R \neq 120\ \text{N} + 140\ \text{N} = 260\ \text{N}$.

$R_x$, $R_y$: cateti; $\vec R$: ipotenusa

Il modulo si ricava con il teorema di Pitagora:

Modulo della risultante

$$R = \sqrt{R_x^{\,2} + R_y^{\,2}}$$

$$R = \sqrt{244^2 + 66^2}\ \text{N} \approx 253\ \text{N}$$
