Forza di attrito statico massima

Corpo fermo su un piano, spinto da una forza $F$: quanto vale l'attrito statico?

  • $F$ minore di $\mu_s F_\perp$ → corpo fermo, attrito uguale e opposto a $F$;
  • $F$ uguale a $\mu_s F_\perp$ → corpo sul punto di partire;
  • $F$ maggiore di $\mu_s F_\perp$ → corpo in moto.

L'attrito si adegua alla forza applicata fino a un valore massimo:

Attrito statico massimo

$$F_s^{\,\max} = \mu_s\,F_\perp$$

Attenzione

$\mu_s F_\perp$ è una soglia, non il valore dell'attrito in ogni situazione.

Forza inclinata

Forza inclinata di $\alpha$ sull'orizzontale, diretta verso il piano

Oltre al peso preme sul piano la componente verticale $F_y = F\operatorname{sen}\alpha$:

$$F_\perp = F_P + F_y = F_P + F\operatorname{sen}\alpha$$

Esempio

Dati: piano orizzontale, $F_P = F_\perp = 100\ \text{N}$, $\mu_s = 0{,}4$, spinta orizzontale crescente. Calcolare l'attrito per $F = 10,\ 30,\ 40,\ 50\ \text{N}$.

$$F_s^{\,\max} = \mu_s\,F_\perp = 0{,}4\cdot 100\ \text{N} = 40\ \text{N}$$

  • $F = 10\ \text{N}$ → $F_s = 10\ \text{N}$, fermo;
  • $F = 30\ \text{N}$ → $F_s = 30\ \text{N}$, fermo;
  • $F = 40\ \text{N}$ → $F_s = 40\ \text{N}$, sul punto di partire;
  • $F = 50\ \text{N}$ → $F_s = 40\ \text{N}$, in moto.

$F_P = 100\ \text{N}$, $\mu_s = 0{,}4$
